# relative_time

`src/relative_time.js` — State History 카드에 표시하는 "방금 전", "3분 전", "2시간 전", "1일 전" 문구를 만든다. DOM과 무관한 순수 함수다.

## 엣지 케이스

| ID | 상황 | 기대 동작 | 테스트 | 상태 |
| --- | --- | --- | --- | --- |
| EC-001 | `null`, `undefined`, 문자열, `NaN`, `Infinity` | `TypeError` | EC-001 숫자가 아니거나 유한하지 않으면 TypeError | 통과 |
| EC-002 | 1분 미만, 시계가 뒤로 조정되어 음수 | "방금 전" (미래 시각 표시 안 함) | EC-002 1분 미만과 음수(시계 역행)는 "방금 전" | 통과 |
| EC-003 | 분, 시간, 일 경계값 | 내림한 단위로 표시 | EC-003 분, 시간, 일 경계 | 통과 |
