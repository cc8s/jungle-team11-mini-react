# app

`src/app.js`, `index.html`, `style.css` — Virtual DOM, diff, patch, State History를 눈으로 검증하는 웹페이지.

## 실행

```bash
node scripts/serve_static.js
```

브라우저에서 `http://localhost:4173`을 연다. ES 모듈은 `file://`에서 로드되지 않으므로 정적 서버가 필요하다.

## 흐름

1. 페이지를 로드하면 실제 영역의 샘플 HTML을 Virtual DOM(`v0`)으로 변환하고, 그 트리로 실제 영역을 다시 그리고(북마크 연결), 테스트 영역에 HTML로 보여 준다.
2. 테스트 영역을 고치면 Patch 버튼이 켜진다. 이전 상태를 보고 있을 때는 수정이 없어도 켜진다(끌어올리기용).
3. Patch: 테스트 영역 → Virtual DOM → 현재 트리와 노드 공유 → 이력 확정 → diff → 바뀐 부분만 실제 영역에 patch → 요약, 연산 로그, 하이라이트.
4. 뒤로가기/앞으로가기/이력 칩: 현재 트리와 목표 트리를 diff해서 차이만 patch하고, 테스트 영역도 목표 트리로 바꾼다. Patch하지 않은 편집은 버리고 알려 준다.

DOM과 무관한 로직(이력 규칙, diff, 요약)은 각 모듈 문서에서 단위 테스트로 검증한다. 이 모듈은 그 함수들을 화면에 연결만 한다.
