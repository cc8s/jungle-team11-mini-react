# app

`src/app.js`, `index.html`, `style.css` — Virtual DOM, diff, patch, State History를 눈으로 검증하는 웹페이지.

## 실행

```bash
node scripts/serve_static.js
```

브라우저에서 `http://localhost:4173`을 연다. ES 모듈은 `file://`에서 로드되지 않으므로 정적 서버가 필요하다.

## 레이아웃

| 영역 | 내용 |
| --- | --- |
| 상단 바 | 가운데에 현재 페이지 제목과 상태(`v1 · 상태 3개`)만 둔다 |
| 좌측 사이드바 | 페이지 선택(Phase 1, Phase 2)만 둔다. 접기 버튼(외곽선 없음)은 펼쳤을 때 `Pages` 글자와 양끝 정렬, 접었을 때 1번 위 가운데. 아이콘은 숫자 1, 2이고 현재 페이지는 겉박스 없이 검정 배지와 굵은 글자로만 표시. 접으면 숫자만 남는 68px 레일 |
| 가운데 본문 | 요구사항의 두 영역만 둔다: 실제 영역, 테스트 영역(1 : 1.25). 테스트 영역 제목 옆에 뒤로가기·앞으로가기·Patch 버튼. 카드 안쪽 폭이 380px 이하면 이동 버튼은 화살표만, 본문 폭이 700px 이하면 두 영역을 위아래로 쌓음 |
| 우측 State History | 확정한 상태를 최신순 카드로 표시(번호, 요약, 상대 시간). 현재 상태는 "현재" 문구나 검정 테두리 없이 흰 배경 카드와 검정 `v` 배지로만 표시하고, 나머지 카드는 배경과 테두리 없이 글자만(마우스를 올리면 연한 회색). 카드를 누르면 그 상태로 이동 |

- 바깥 박스 없이 화면 전체를 쓴다. 실제 영역·테스트 영역 카드와 히스토리 카드에는 외곽선이 없다.
- 스타일: 밝은 회색 배경, 흰 카드, 회색·진회색·검정 글자, Pretendard 글꼴(jsDelivr CDN, 없으면 시스템 글꼴). npm 패키지가 아니라 CSS 글꼴 파일이므로 `package.json` 의존성은 그대로 비어 있다.
- 사이드바 접힘 상태는 `localStorage`에 기억한다. 저장소를 쓸 수 없으면 기억하지 않는다.
- 1080px 이하: 히스토리가 본문 아래로 내려가고 페이지 전체가 스크롤된다. 720px 이하: 사이드바는 레일로 시작하고, 펼치면 본문 위에 겹쳐 뜨며 항목을 고르면 닫힌다.

## 흐름

1. 페이지를 로드하면 실제 영역의 샘플 HTML을 Virtual DOM(`v0`)으로 변환하고, 그 트리로 실제 영역을 다시 그리고(북마크 연결), 테스트 영역에 HTML로 보여 준다.
2. 테스트 영역을 고쳤을 때만 Patch 버튼이 켜진다. 이전 상태를 보고 있어도 수정이 없으면 꺼져 있다.
3. Patch: 테스트 영역 → Virtual DOM → 현재 트리와 노드 공유 → 이력 확정 → diff → 바뀐 부분만 실제 영역에 patch → 하이라이트(주석·공백처럼 화면에 안 보이는 변경은 제외), 히스토리 카드 갱신(변경 요약은 카드에 표시).
4. 뒤로가기/앞으로가기/히스토리 카드: 현재 트리와 목표 트리를 diff해서 차이만 patch하고, 테스트 영역도 목표 트리로 바꾼다. Patch하지 않은 편집은 버린다.
