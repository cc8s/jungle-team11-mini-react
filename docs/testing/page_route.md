# page_route

`src/page_route.js` — 주소의 hash(`#phase1`, `#phase2`)로 보여 줄 페이지를 정한다. hash를 쓰면 정적 서버만으로 새로고침과 뒤로가기(브라우저)가 동작한다. DOM과 무관한 순수 함수다.

## 엣지 케이스

| ID | 상황 | 기대 동작 | 테스트 | 상태 |
| --- | --- | --- | --- | --- |
| EC-001 | `#phase1`, `#phase2`, 대문자와 뒤 공백, `#` 없는 이름 | 해당 페이지 | EC-001 알려진 hash는 해당 페이지, 대소문자와 공백은 무시 | 통과 |
| EC-002 | 빈 hash, `#`, 모르는 이름, 문자열이 아닌 값 | 기본 페이지 `phase1` | EC-002 빈 hash, 모르는 hash, 문자열이 아닌 값은 기본 페이지 | 통과 |

| EC-002 빈 hash, 모르는 hash, 문자열이 아닌 값은 기본 페이지 | 기본값 | EC-002 |
