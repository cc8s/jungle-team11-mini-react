# hook_dependencies

`src/hook_dependencies.js` — `use_effect`, `use_memo`의 의존성 배열 비교. DOM과 무관한 순수 함수다.

- 처음 렌더링(이전 의존성 없음)과 의존성 생략(`undefined`)은 항상 "바뀜"이다.
- 값 비교는 `Object.is`다. 그래서 `NaN`은 `NaN`과 같고, `+0`과 `-0`은 다르며, 내용이 같아도 다른 객체는 다르다.
- 저장하는 의존성은 복사해 동결한다. 컴포넌트가 넘긴 배열을 나중에 고쳐도 비교 기준이 바뀌지 않는다.
