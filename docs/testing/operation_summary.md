# operation_summary

`src/operation_summary.js` — patch 연산을 "N개 변경 반영 (ADD 1, TEXT 2)" 요약과 연산별 설명 문장으로 바꾸는 순수 함수.

## 엣지 케이스

| ID | 상황 | 기대 동작 | 테스트 | 상태 |
| --- | --- | --- | --- | --- |
| EC-001 | 연산 없음 | "변경 사항이 없습니다" | EC-001 연산이 없으면 "변경 사항이 없습니다" | 통과 |
| EC-002 | `BIND`가 섞임, 종류 순서가 뒤섞임 | `BIND`는 세지 않고 정해진 순서(ADD, REMOVE, REPLACE, MOVE, TEXT, ATTRIBUTES)로 표시 | EC-002 BIND는 세지 않고 종류는 정해진 순서로 표시한다 | 통과 |
| EC-003 | 입력이 `null`, `undefined`, 문자열, 객체 | `TypeError` | EC-003 배열이 아니면 TypeError | 통과 |
| EC-004 | key 있는 요소, 24자 넘는 텍스트, 공백만 있는 텍스트, 주석, 루트, `null` | 각각 읽기 쉬운 짧은 설명 | EC-004 노드 설명: key, 긴 텍스트 줄임, 공백 텍스트, 주석, 루트, 없음 | 통과 |
| EC-005 | 모든 연산 종류가 섞인 diff | 종류별 설명 문장 | EC-005 연산 종류별 설명 문장 | 통과 |
